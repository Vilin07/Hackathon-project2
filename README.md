# ✨ Sakhi – Rural Girls Empowerment Platform

🔗 Live Demo: https://sakhi-eta.vercel.app/main.html

---

## 🌍 About the Project

**Sakhi** is a tech-driven rural empowerment platform designed to enhance **safety, awareness, and digital accessibility for girls in underserved communities**.

This project goes beyond a basic website — it integrates real-world safety features, authentication systems, and multilingual support to create a meaningful social impact.

---

## 🚀 Key Features

### 🔐 Safety & Emergency System
- Real-time SOS emergency alert system
- Quick-access safety trigger for emergency situations
- Designed for fast response and user protection

---

### 📍 Live Location Tracking
- Captures and sends user location during emergency alerts
- Helps simulate real-world rescue coordination systems
- Integrated with browser geolocation APIs

---

### 🔄 Firebase Integration
- Firebase Authentication (Login / Signup system)
- Firestore Database for real-time data storage
- Secure backendless architecture for scalability

---

### 🌐 Multilingual Accessibility
- Google Translate integration
- Supports multiple regional languages
- Makes the platform accessible for rural users

---

### 💬 Anonymous Reporting System
- Users can report issues anonymously
- Encourages safe and secure communication
- Stored securely in Firebase Firestore

---

### ⚙️ Additional Integrations
- API-based services for alerts and data handling
- Responsive UI for mobile and desktop users
- Smooth navigation and interactive frontend experience

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Firebase (Auth + Firestore)  
- Google Translate API  
- Geolocation API  
- Vercel (Deployment)
